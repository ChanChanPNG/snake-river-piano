# Snake River Piano — updated website

Responsive one-page website for Diana Williams, Blackfoot, Idaho.

## Deployment

1. Extract the ZIP file.
2. Upload **the contents of the `snake-river-piano` folder** (including `assets/`) into the root of your GitHub repository.
3. Import the repository into Vercel as an **Other** / static site project, or push the changes to an already connected repository. No build command is necessary.
4. Use the Vercel preview URL to check the site before changing any domain DNS settings.

## Content

Piano Lab costs $65/month and is for ages 6–18. After-school options serve families in the Blackfoot and Snake River School Districts; morning classes are offered for homeschool families. The exact timetable is intentionally not published pending confirmation.
